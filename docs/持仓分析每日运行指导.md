# 持仓分析每日运行指导

## 目的

每次手动或定时运行时，使用仓库中当日最新的市场概况、持仓行情与持仓分析数据，生成一份证据可追溯、结论克制的组合运营分析。每天都必须完整执行分析流程，但不要求每天产生买入或卖出建议；证据不足、条件未确认或组合约束不支持时，结论应为继续观察或无法判断。

本文件规定分析过程和输出结构，不规定每日市场判断、目标仓位、ETF 名单或交易动作。

## 输入与数据检查

1. 读取仓库中当前版本的公开市场概况、`持仓分析报告.md`、`data/packets/positions_packet.json`（如本次运行已生成）及本文件引用的规则配置。持仓文件由用户在其本机工作流中用口令解密；口令只用于解密，不得回显、写入提示记录、报告、提交内容或日志。
2. 先列明本次分析的运行时间、行情数据日、各主要市场数据日期、来源、持仓分析状态、数据质量，以及组合基准比较的日期窗口和可比权重覆盖率。
3. 将 `OK`、`DEGRADED`、`ABSTAIN`、`DEMO`、`ERROR` 按输入中的定义处理。陈旧、合成、缺失、日期不一致或基准未映射的数据不得当作有效确认信号；缺失不代表条件满足。
4. 仅使用输入材料中明确提供的数值和事实。外部新闻、宏观或政策信息如未出现在本次数据中，不得凭模型记忆补充；如工作流另外检索外部信息，必须列出可核验来源与发布日期/数据日期，并区分它与模型结构化行情证据。
5. 不得将沪深300作为所有资产的统一基准。逐只持仓使用配置中对应的跟踪指数/基准；组合比较只汇总同窗、可比且通过质量检查的成分，并同时报告覆盖率。若窗口、映射或数据不足，明确不可比，不外推到全组合。

## 固定分析流程

### 一、资金健康与持仓盈亏

- 描述总资产、现金、持仓市值、总仓位、风险资产仓位、浮动盈亏和成本口径。说明这是持仓快照/浮动盈亏，不是真实账户累计绩效（除非提供并核验了完整交易流水）。
- 对照市场状态、市场数据日、模型仓位区间、当前仓位、现金需求、集中度、类别/风险桶暴露、相关性和数据质量，说明资金状态的支持证据、冲突证据与未知项。
- 报告持仓与各自匹配基准的共同窗口收益/超额表现或现有数据提供的加权相对强弱，并说明基准覆盖及比较限制。不可仅凭累计浮盈亏判断跑赢/跑输市场。
- 汇总规则层逐腿动作、组合层动作、执行后静态模拟和约束结果。将“规则建议”“可执行订单”“模拟结果”分开；不得把静态目标份额表述为已成交。
- 按实际证据给出加仓、减仓、建仓、持有或继续观察建议。若无足够证据或规则动作互相冲突，明确不操作/等待，不为了形成结论而强行交易。

### 二、现有持仓逐只 ETF 分析

对每一只持仓按以下顺序撰写：

1. **事实**：代码、类别/风险桶、跟踪指数/基准、当前权重、成本口径盈亏、行情日期、趋势/均线/量能/相对强弱/折溢价等输入中实际存在的指标。
2. **市场关系**：说明市场状态、对应指数/基准的同期表现、可明确匹配的行业/主题变化，以及其与该 ETF 走势的关系。每个关系须给出数据日期和来源；没有明确映射时写“关联数据不可用”，不得按名称或印象推断板块因果。
3. **组合影响**：说明该持仓对仓位、集中度、类别/风险桶和现金安排的实际影响；不得把单只技术信号脱离组合约束解释为独立买卖命令。
4. **判断与反证**：说明支持当前规则等级/动作的可观测证据、反向证据、缺失数据和模型无法判断的部分。区分事实与解释，不使用“主力意图”等不可观测因果作为证据。
5. **条件式建议**：仅复述并解释规则决策契约中的动作和执行门禁。列出触发条件、失效条件、资金来源/约束（如适用）；未达到条件则写明继续观察。不得因为浮亏或“便宜”单独建议加仓。

### 三、市场新动向与候选关注方向

- 从本次公开市场概况中提取相对上一可用数据日的可核查变化，注明指标、数值、日期和来源。没有历史对照时只描述当前观察，不称为“新变化”。
- 关注方向按市场/板块层证据排序，说明趋势、相对强弱、量价/波动变化、持续性证据、反证和数据质量。区分已确认与待确认方向。
- 具体 ETF 只能来自本次分析提供的观察池/候选池或明确的市场数据映射。逐项列出代码、名称、跟踪指数、候选状态（`READY`、`WAIT_CONFIRMATION`、`WATCH`、`AVOID`、`ABSTAIN`）、支持/反对证据、触发条件、失效条件，以及现金、集中度、类别、相关性、费用和腿数门禁结果。
- `READY` 只表示规则与组合约束允许进入研究性方案，仍需用户确认，不等于必须建仓。未有候选通过时，明确写“当前没有满足条件的新增方向，继续观察”，不补造替代 ETF。
- 不输出未经校准的胜率、上涨概率、目标收益或模型未提供的买卖价格/权重。只有输入决策契约明确提供的执行参考才能原样引用，并注明非成交承诺。

## 输出结构

每次输出按以下固定标题组织，不省略空结果说明：

1. **运行与数据可信度**：运行时间、行情日期、来源、状态、质量缺口、基准比较窗口与覆盖率。
2. **资金健康与市场位置**：资金快照、浮盈亏口径、持仓与匹配基准比较、风险预算/集中度、组合动作概览和执行后静态模拟。
3. **逐只持仓分析**：每只 ETF 使用“事实—市场关系—组合影响—判断与反证—条件式建议”。
4. **市场新动向与关注方向**：变化证据、关注方向、具体候选状态与门禁；无候选时写继续观察。
5. **综合结论**：当前最重要的组合风险、可采取的行动或暂不行动的理由、下一次需要核对的触发/失效条件。结论必须与结构化规则动作一致。

## 一致性与安全约束

- 不得修改或重新推导 `action`、`candidate_state`、目标权重/份额、订单、风险门禁、规则阈值；如报告解释与数据包不一致，以结构化决策契约为准并标出冲突。
- 每个具体数字、行情事实和候选结论都应能指向输入中的字段/证据、数据日期和来源；没有依据的内容删除或标为未知。
- 不制造每日必须买卖的节奏。无动作是有效结论，等待确认也是有效建议。
- 不输出、复制、上传或持久化解密口令；不把口令放入 GitHub 文件、提交信息、分析报告或自动化日志。遵循用户本机的密文解密流程与仓库权限设置。
- 本分析为研究辅助，不构成收益保证或自动交易指令。
