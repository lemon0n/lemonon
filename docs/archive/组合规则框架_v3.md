# 组合规则框架 v3：状态 → 目标仓位 → 条件执行

> 设计原则：不做“每天全仓/清仓”，也不做“每次固定分批”。
> 规则只回答三件事：现在是什么状态、合理仓位是多少、离目标差多少才动手。
> 本文是设计稿，阈值需回测后才能进入 `config/`。

## 1. 为什么之前的规则太绝对

现有 10 条规则是“条件 → 固定动作”：

- 触发就清仓，或触发就减半
- 不看当前仓位离合理仓位有多远
- 不看月线/周线方向
- 不看波动率和事件窗口
- 减仓固定 50%，加仓固定 5%

结果就是：震荡市里反复清仓、反复追回，换手高、回撤大。

## 2. 四个 skill 的分析思路拆解

### 2.1 a-share-turning-point（ETF 大波段拐点）

它的核心不是“信号”，而是一个**状态机**：

- **月线定牛熊**：20 月均线是分界。站上 → 可重仓；下方 → 一切上涨先按反弹，轻仓参与（注意不是 0 仓）。
- **周线定节奏**：5/10/20/30 周均线排列 + MACD。
- **日线定点位**：延 5 切 10。
  - 跌破 10 日线：短线走弱，观察
  - 跌破 20 日线且 2 日不收回：减仓 50%
  - 跌破 30 日线且 2 日不收回：清仓
  - 跌破 60 日线：趋势逆转
- **品种分线**：进攻型看 20 日，防御型看 30 日，周期型看 MACD 零轴 + 60 日。这一点比“所有 ETF 都看 MA10”合理。
- **评分定仓位上限**：S 25% / A 20% / B 10% / C 5% / D-F 0%。
- **加仓需右侧确认**：站上 10 日线、MACD 金叉、资金连续 2 日流入，至少满足两条。
- **不同市场阶段的总仓位**：牛市 75–80%，震荡上行 60–70%，震荡 40–50%，下跌 20–30%。下跌趋势也不是 0 仓。
- **事件静默**：议息、CPI、政治局会议前 48 小时不主动加减。
- **纪律**：单板块 -5% 止损、-3% 组合回撤复盘、不卖强买弱、阶梯止盈。
- **不建议照搬**：固定三批减仓、固定止盈比例、永久不碰名单（个体偏好）。

### 2.2 national-team-positions（国家队份额）

- 用上交所 ETF 份额变化估计汇金加减仓，覆盖 6 个宽基。
- 分析重点不是绝对值，而是**增量与轮动**：沪深 300 见顶后资金是否流向 A500；区分“真减仓”和“换仓”。
- 科创 50、中证 500、A500 噪音大，看趋势不看单日。
- 适合做**背景层**：调节核心仓下限，不直接生成买卖。

### 2.3 topnews（舆情）

- 美股、期货、财联社快讯（情感分类）、宏观、北向与两融。
- 输出当日“偏多/偏空/震荡”和分风格建议。
- 适合做**环境层**：解释今天为什么偏防守，不进入规则谓词。

### 2.4 quant-backtest-strategy / a-quanttrader-pro

- 本质是同一个 OneQuant 4.0 本地 Flask 系统，102 个 API，数据源 RQ/JQ/AkShare。
- 能力重叠、部署重；只借回测协议、成本口径、风控指标，不整套搬。

## 3. v3 框架

### 3.1 第一层：状态识别

| 状态 | 取值 | 来源 |
|---|---|---|
| 月线区域 | 牛 / 熊 | 收盘 vs 20 月均线 |
| 周线方向 | 上 / 平 / 下 | 5/10/20/30 周排列 |
| 日线阶段 | 强 / 弱 / 转换 | 5/10/20/30/60 日关系 |
| 市场状态 | 上行 / 震荡 / 下行 | 现有 regime |
| 波动 | 低 / 中 / 高 | 20 日年化波动 |
| 结构评分 | 0–100 | 底部评分卡简化版 |
| 国家队 | 增 / 平 / 减 | 宽基份额增量 |
| 事件窗口 | 正常 / 静默 | 宏观日历 |

### 3.2 第二层：目标仓位（不是动作）

```
目标仓位 = 区间基准 × 评分系数 × 波动系数
```

- 区间基准：沿用现有 `regime_fit`，但**下跌趋势给核心仓下限**（宽基 20%），不归零。
- 评分系数：0.6（低分）~ 1.0（高分），按评分卡分档。
- 波动系数：`min(1, 目标波动 / 当前波动)`，波动越高仓位越低。
- 单只上限：S 25% / A 20% / B 10% / C 5%。
- 相关性：同向相关 >0.7 的腿合并计算，超过 60% 降级。
- 核心/卫星：宽基为核心，行业为主题卫星；核心不参与逐腿清仓。

### 3.3 第三层：条件执行（不再是固定批次）

先算差额：`gap = 目标仓位 - 当前仓位`。

| 情况 | 动作 |
|---|---|
| `|gap| < 3%` | 不动（避免每天折腾） |
| `gap > 0` 且周线向下 | 不买 |
| `gap > 0` 且满足 ≥2 条确认（站上 MA10 / MACD 金叉 / 资金流入） | 买入，单次金额 = min(gap, 1% 权益 / 波动, 流动性上限) |
| `gap < 0` 且只是跌破 10 日线 | 只把超出目标的部分卖到目标，不额外清仓 |
| `gap < 0` 且跌破 20 日线 2 日不收回 | 卖出 gap 的一半 |
| `gap < 0` 且跌破 30 日线 2 日不收回 | 卖出全部 gap |
| 跌破 60 日线 / 触及硬止损 | 立即卖出全部 gap |
| 事件静默期 | 不新增风险，只允许设条件单 |
| 清仓后收复 MA10 且周线不向下 | 回补 gap 的 1/3，不追高 |

关键区别：

- 不是“每天必须动”，多数日子 `gap < 3%` 就不动。
- 不是“固定 1/3、1/2”，每次金额由差额、波动和流动性决定。
- 退出看的是“离目标多远”，不是“今天触发了什么”。

### 3.4 第四层：解释

每只持仓输出五段：

1. 一句话：今天做什么
2. 状态：月/周/日、评分、市场、国家队
3. 目标 vs 当前，gap 多少
4. 为什么现在动/不动，反证是什么
5. 什么条件下改（失效/回补）

## 4. 规则来源怎么标注

### 5.1 v3 真实回测（目标仓位 + 差额执行）

已把 v3 写进回测引擎（`run_portfolio_v3`），与旧规则在同一标的池、
同一区间、同一费率口径下对比。16 只 ETF，2023–2024 训练、2025 验证，
最终测试期未跑。

| 阶段 | 方案 | 年化 | 最大回撤 | Sharpe | 换手 | 完整平仓 | 部分减仓 | 盈利因子 | 平均持仓数 | 平均仓位 |
|---|---|---|---|---|---|---|---|---|---|---|
| 训练 2023–24 | 旧规则 | -4.23% | -12.08% | -0.41 | 14.26 | 83 | 50 | 0.741 | 1.70 | 25.6% |
| 训练 2023–24 | v3 | -1.35% | -5.79% | -0.21 | 4.93 | 28 | 147 | 0.844 | 3.69 | 30.9% |
| 验证 2025 | 旧规则 | 5.92% | -7.26% | 0.65 | 12.23 | 30 | 28 | 1.320 | 1.58 | 24.9% |
| 验证 2025 | v3 | 8.57% | -5.82% | 1.02 | 6.43 | 19 | 104 | 1.717 | 3.33 | 33.0% |

结论：

- 两段回撤都明显收敛（训练 -52%，验证 -20%），Sharpe 两段均改善；
- 换手降到旧规则的 1/3～1/2，说明「差额不足不动」确实减少了每天折腾；
- 完整平仓次数大幅下降、部分减仓次数上升：亏损时不再整仓清零，
  而是按目标仓位分批退出，符合要解决的原始问题；
- 训练期年化仍为负，说明 2023–24 的震荡下行本身难赚钱，v3 只是亏得更少、
  回撤更浅，不应解读为「已找到盈利策略」。

判定：两段均达到「回撤改善 ≥15% 或 Sharpe ≥+0.15、年化不低于基准 −1pct、
活动笔数 ≥10」的门槛，综合 PASS；最终测试期仍未运行，需用户确认后再跑一次。
