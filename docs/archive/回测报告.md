# 回测报告 · 引擎 v2（生产同源信号 + 组合约束 + 时间隔离）

## 零、旧结论撤回（不可再引用）

此前 `docs/回测报告.md` 中的以下表述已作废，原因是实现与口径缺陷，不是「结果不好」：

1. 「样本外年化 6.04% / 夏普 1.01 / 胜率 74.7%」——胜率把每次部分卖出记为一笔、`pnl_pct` 未扣费、按百分比简单求和；
2. 「仅重叠 1 只，构成真正意义上的独立验证集」——两个样本实际共同包含 `159915` 与 `512100`，且使用同一段历史时期；
3. 该「样本外」结果被用于最终选参（R3），因此它已是验证集，不是一次性测试集；
4. 仓位口径为「剩余现金 × 15%」递减排权（6 次累计 62.29%），不是 90% 仓位；
5. 回测入场未包含生产 `R-A1` 的 `true_breakout` 条件，上影线取的 K 线与生产不同。

本文件下方结果是**修复后引擎**的重新计算，与旧数字无任何可比性。

- 引擎：`src/etfquant/backtest/engine.py`（T 日收盘信号 → 下一可交易日开盘成交）
- 信号：与生产共用 `features.frame` + `methodology.decide`（含 true_breakout、上影线取倒数第三根、假突破定义一致）
- 费用：单边佣金 0.5bp + 最低佣金 ¥5 + 滑点 1.0bp；ETF 免印花税
- 标的池：固定 16 只（非随机抽样）：510300、510500、588000、159915、512100、510880、512000、512880、512480、159995、512690、512800、512660、515790、512400、518880
- 时间切分：训练 2023-01-01~2024-12-31 / 验证 2025-01-01~2025-12-31 / 最终测试 2026-01-01~2026-11-12

## 四、必读局限

- 固定池、固定区间，非随机抽样；池内标的共享同一段市场，「跨标的」不等于「跨时间独立」；
- 不建模盘中触发、涨跌停不可成交、部分成交与成交量冲击；
- 回测目标权重是固定上限（15.0% × 6 腿），与生产按市场状态给出的 仓位区间不是同一口径，不能互相背书；
- 未接入 IOPV/份额/申赎数据，折溢价条件在回测中恒不命中；
- 最终测试只允许看一次；若看过之后修改规则，该区间即变为验证集。
