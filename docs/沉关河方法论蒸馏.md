## 第四部分 · 固化分析流程规格（CO-STAR）

此规格即模型重构后的「固有流程」，每交易日收盘后执行一次，全程无人工提示句，输出结构化数据。

- **C（Context）**：A 股 ETF，T+1 结算，日频数据（开高低收+量），无盘中轮询。
- **O（Objective）**：按蒸馏规则输出持仓层与逐腿层的可执行动作清单（仓位核对→结构核对→逐腿分诊→动作生成→组合输出）。
- **S（Style）**：数据驱动、规则编号可回查、无叙述性废话；每条结论必须能映射回第三部分规则卡编号。
- **T（Tone）**：中性、克制、无情绪词（源方法论反对情绪化表达，输出同样遵守）。
- **A（Audience）**：模型使用者本人（持仓数据本地加密，分析在本机完成）。
- **R（Response）**：固定五步 JSON 结构（前端直接渲染为表格，不再生成说明句）。

### 五步流程（S1-S5）

```
S1 大盘定仓    regime 判定（L1-01~04）→ 适配仓位区间 → 当前总仓位对比 → 仓位动作码
S2 结构核对    类别占比 vs 目标结构 → 偏离标记（±5pct 阈值）
S3 逐腿分诊    每只持仓：指标(MA/量/结构/溢价) → 相对强弱(L3-06) → 分诊 A/B/C/D
S4 动作生成    规则表按优先级求值：D(清仓) > C(减仓) > 加仓条件 > 持有
               → 动作码 + 触发价 + 止损价 + 止盈价 + 命中规则编号
S5 组合输出    今日操作清单（含规则号与出处）+ 风险标记汇总 + 组合健康分
```

分诊等级与动作映射（优先级 D > C > A > B）：

| 等级 | 触发（任一命中） | 动作码 | 对应规则 |
|---|---|---|---|
| D | 连两日收盘 < MA10；放量下跌破 MA20；假突破成立 | `CLEAR` 清仓 | L4-03 / L3-04 |
| C | 跌破 MA5 + 放量滞涨；上影线 >2%；折溢价偏高 | `TRIM` 分批减仓 | L4-06 |
| A | 站回 MA5 ≥2 日 + 确认项（缩量回踩 / 真突破 / 先于大盘企稳）；加仓需 ≥3 日 | `ADD`/`HOLD` | L3-03 / L2-02 / L4-02 |
| B | 均线缠绕缩量整理，缺确认 | `HOLD` 底仓等待 | L1-11 |

组合层覆盖规则（优先于逐腿加仓）：超配 → 所有 `ADD` 降级 `HOLD`（L4-05）；浮亏腿 → `ADD` 降级 `HOLD`（L4-08）。

## 第五部分 · ETF 适配与已知局限

蒸馏方法原本针对个股（主力行为、筹码结构），映射到 ETF 时做如下适配，并如实列出局限：

| 原概念 | ETF 适配 | 局限 |
|---|---|---|
| 主力吸筹/试盘/出货 | 一篮子股票的资金合力，用「板块五均线企稳三日 + 缩量回踩」近似 | ETF 无单主力，L3-05 的博弈逻辑弱化 |
| 120 日线（趋势多空转折） | 保留为长周期过滤器 | 宽基与行业 ETF 阈值敏感度不同 |
| 放量/缩量判定 | 用基金份额成交额近似 | ETF 做市与申赎会干扰量能口径 |
| 打板 / 情绪高标（E 系列） | 不适用于 ETF，仅保留指数级情绪（涨跌家数、成交额环比） | 情绪周期维度对 ETF 只有间接价值 |
| 折溢价 | ETF 特有：溢价 >1% 视为追高风险 | 原方法论无此概念，为组合自有的工程护栏 |

**回测验证（M5 闭环）**：规则参数（缩量阈值 0.8、放量阈值 1.3、站上 MA5 日数 3、止损 MA10 连两日等）在历史数据上执行了 3 轮优化，结果见《回测报告》。最终参数写入 `config/methodology.yaml` 与 `config/strategy.yaml`。
