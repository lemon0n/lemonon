v3 优化演示：状态 → 目标仓位 → 差额执行

研究用演示：仅训练期与验证期，最终测试期未运行；不改线上配置，不构成投资建议。
1. 状态基准收盘 vs MA20/MA60、波动升降 → 上行 / 震荡 / 下行
2. 目标仓位区间中枢（如震荡 65%）× 评分 × 波动系数，分给前 N 只
3. 差额gap = 目标 − 当前；|gap|<3% 不动
4. 条件执行买入要周线不向下+2 条确认；卖出按 MA10/20/30/60 分级
  • 不再「触发即清仓」：亏损时卖的是超出目标的那部分，不是整仓。
  • 不再「固定分批」：每次金额由差额、波动和单只上限决定。
  • 不再「每天必动」：多数日子差额不足 3%，保持不动。
