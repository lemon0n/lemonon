# 持仓分析页 · 施工指南（终版）

从零搭这个页面的完整说明：每一块显示什么、判断从哪来、没有数据怎么显示、写在哪、怎么验收。
适用范围：`web/index.html` 第 5 页「持仓分析」（持仓概况 / 持仓分析 / 市场洞察及方向）。
不构成投资建议，不预测点位。

**三条底线**

- 页面不写死业务数字：行业权重、候选名单、评级分数线、点评句子，全部由数据与规则算出来。
- 每个数字都有出处：哪个文件、哪个字段、哪次运行。
- 一句结论里的数字，必须能在同一页找到那个数；找不到就不写这句话。

**一句话验收**：把页面上任意一句结论单独拿出来，读者都能在同一页找到支撑它的数字；找不到，就是不合格。

## 2. 页面结构

### 2.1 三部分，各回答一个问题

| 部分 | 回答 | 读者动作 | 篇幅 |
|---|---|---|---|
| 一、持仓概况 | 我有多少钱、赚亏多少、今天买卖什么、多少份什么价 | 直接照着下单 | 一屏 |
| 二、持仓分析 | 市场什么环境、组合跟不跟得上、每只为什么留或减 | 判断要不要改计划 | 越长越细 |
| 三、市场洞察及方向 | 大盘在什么位置、情绪冷热、三种走法怎么办、还能看什么 | 做下周打算 | 中等 |

顺序不可倒：**先给结论，再讲理由，最后讲远景**。理由只能收紧结论，不能推翻结论。

### 2.2 一屏原则

概况只放三类东西：四个数字、一段点评、一张能下单的表。
不放：仓位条、持仓类别饼图、执行后估算卡、今日建议卡、表下小字说明、收益曲线。这些内容已经在表里或点评里，重复即噪音。

### 2.3 命名

| 写法 | 例子 |
|---|---|
| 名字（代码） | 沪深300ETF（510300）、科创50ETF（588000） |
| 只写代码 | 仅限表格「代码」列与函数参数 |
| 行业名 | 用板块快照里的名字：电子、银行、电力设备… |

首次出现写全，后文可只写名字。禁止只给一串数字让读者自己查。

### 2.4 三部分的视觉重心

- 概况：数字大、留白多，表格行高足够点得准。
- 分析：分层小标题明显（1. 市场环境 / 2. 组合情况 / 3. 个股分析），每层开头一句话结论，再展开证据。
- 洞察：表格化（情景三行、候选一表），少用长段。

## 3. 决策链：五层，一个出口

### 3.1 先说旧版为什么割裂

旧页面不是数据不够，而是**四套判断同时在跑**：

| 位置 | 它在说什么 | 谁听谁的 |
|---|---|---|
| 规则卡（methodology） | 这只触发减仓 | 不知道有没有人执行 |
| 目标仓位表（plan_v3） | 这只该占 8.9% | 与规则卡的动作不保证一致 |
| 执行后估算 | 执行完还剩多少仓 | 自己算一遍，与表里的数量对不上 |
| 持仓分析（技术） | 日线转强、缠论买点 | 与上面的减仓正好相反 |

修复只有一条：**把动作收敛到一个出口，其他层只能收紧，不能另起一套。**

### 3.2 五层与唯一出口

```
L0 数据闸门   行情/持有/行业权重/舆情是否可用；不可用就只说事实
   ↓
L1 环境层     大盘状态 → 总仓位上限（35 / 65 / 85，可 ±5）
   ↓
L2 板块层     板块评分 → 板块评级 → 单板块上限、主线覆盖度
   ↓
L3 个股层     三周期 + 双评分卡 + 结构 → 单只上限（25/20/10/5/0）
   ↓
L4 组合层     目标仓位 = min(总上限分摊, 单只上限, 单板块上限) → 差额 → 动作
   ↓                ↓
   ↓          唯一出口：目标仓位表 → 订单（数量、挂单价、费用）
   ↓
L5 解释层     点评、逐只解读、洞察；只能引用 L1–L4 的结论
```

三条传导规则：

1. **额度只能收紧**：L2 拿到的总上限，只能往下压，不能加。
2. **下层不许翻案**：L3 技术再强，若 L2 判该板块 D 级（上限 0），不得加仓。
3. **解释层不许自创**：L5 的动作必须等于 L4；想说的不同，先改 L4。

### 3.3 每层做什么

| 层 | 输入 | 输出 | 不许做 |
|---|---|---|---|
| L0 | 行情、持有、行业权重、舆情、国家队 | 可用 / 降级 / 放弃 + 缺失清单 | 用估算值填空 |
| L1 | 指数日线、涨跌家数、成交额、隔夜、资金、国家队 | 大盘状态、总上限、环境定性 | 指定买哪只 |
| L2 | 行业代表 ETF 周线、板块成交占比、政策热度、当日涨跌 | 板块四维分、评级、覆盖度、过热标记 | 直接给个股数量 |
| L3 | 个股月/周/日线、MACD、量比、相对强度、缠论 | 三周期状态、评分、评级、执行位 | 决定目标仓位 |
| L4 | 上限、评分、当前仓位、现金、约束 | 目标仓位、差额、动作、订单 | 写解释长文 |
| L5 | 以上全部 | 点评、逐只解读、情景 | 改任何数字 |

### 3.4 冲突裁决表（页面显示「冲突 + 裁决」）

| 冲突 | 裁决 |
|---|---|
| 日线转强 / 周线空头 | 以周线定方向，日线只定节奏，不加仓 |
| 月线转换 / 周线空头 | 按周线，不提前埋伏 |
| 目标仓位高于现在 / 周线向下 | 不买，改为等待，写明等什么 |
| 单只上限 / 板块上限 / 总上限 | 三者取小 |
| 缠论买点 / 目标是减 | 不做多，缠论只用于卖出时点 |
| 概率偏低 / 评分较高 | 概率只作参考，不改评级 |
| 舆情或国家队 / 仓位区间 | 最多 ±5 个百分点，不破上下限 |
| 板块走弱 / 该只动作是加仓 | 标橙，降级为「观察」，不新增 |
| 规则卡触发减仓 / 目标仓位仍高 | 以目标仓位为准；规则卡只管最早减仓时点与数据闸门 |

## 4. 第一部分 持仓概况

```
① 四个数字
② 今日点评
③ 持仓明细表
```

### 4.1 四个数字

| 卡 | 大字 | 小字 | 怎么算 | 缺数据 |
|---|---|---|---|---|
| 总资产 | 金额 | 其中现金多少 | 所有持仓市值 + 现金 | 「—」，小字写缺哪只价格 |
| 持仓市值 | 金额 | 持有几只 | Σ 最新价 × 份额 | 同上 |
| 浮动盈亏 | 百分比 | 金额 | Σ（最新价 − 成本价）× 份额 | 缺成本只显示「—」 |
| 当日盈亏 | 百分比 | 金额 | Σ（最新价 − 昨收）× 份额 | 缺昨收显示「—」 |

赚红亏绿、零值灰；金额取整到元加千分位；比例两位小数。
无持仓：只显示总资产与现金，后两卡写「暂无持仓」。

实现：`calcPort()` 计算，`kpi()` 渲染。

### 4.2 今日点评

它不是数据罗列，是一次综合判断。写法照沉关河复盘：**一句结论先行 → 一句定性 → 编号 2–3 点理由 → 怎么做（仓位/买点/止损）→ 一句风险收口**；每段不超过 3 行，短句，不用「综上所述」。

#### 生成方式

1. 主来源：`skills/portfolio-brief` 每日运行，读当次全部结论，写 `data/brief.json`，页面直接读。
2. 兜底：文件缺失或日期不一致，页面用 `rsBriefSections()` 现场生成，标题标注「（本机引擎）」。

点评**只能引用 L1–L4 的结论**，不能自己再判断一次。这是「不再割裂」的关键：点评说减仓，表里的动作就必须是减仓。

#### 必写与禁写

| 环节 | 必须写到 | 不许写 |
|---|---|---|
| 结论 | 基调 + 今天最该做的一件事 | 「注意风险」「保持谨慎」 |
| 环境 | 大盘状态、总上限、当前偏离、量能、情绪温度 | 没数字的形容词 |
| 结构 | 主要矛盾是哪只、哪个板块，为什么 | 四只平均用力 |
| 动作 | 方向、数量、挂单价、分几批；不动的写原因 | 只说「减仓」不给量 |
| 改判 | 阈值 + 后果 | 「密切关注」 |
| 收口 | 「价格是执行价，不保证成交。」 | 收益承诺 |

#### 示例（下行趋势中的减仓日，实际每天不同）

> **今日基调：先降后看。**
>
> 大盘还在 60 日线下方，5 日线压在 20 日线下，近 5 日量能比前 5 日缩了两成，没有放量急杀，所以这是阴跌不是恐慌。总仓位上限 35%，我们现在 40.6%，高出 5.6 个百分点，这一口先还回去。
>
> 1. 四只里三只周线仍是空头排列，只有科创50ETF（588000）日线先转强，但周线没跟上，按纪律不加。
> 2. 真正拖累的是沪深300ETF（510300）：月线在转换期、周线死叉，底部评分 38，评级 D。
> 3. 电子板块成交占比 16.1%，已经过热；我们电子暴露 17.5%，是唯一超配的方向。
>
> 今天动两笔：沪深300ETF（510300）减 2400 份，挂 4.051；中证500ETF（510500）减 800 份，挂 6.312。科创50ETF（588000）不动，等回踩 10 日线再谈。剩余差额按 50/30/20 分三批减完，不一次清仓。
>
> 改判：基准收复 20 日线 4069.52 且 5 日线上穿 20 日线，上限从 35% 上调到 45%；任一只收盘连续两日跌破 30 日线，卖出该只全部剩余差额。
>
> 价格是执行价，不保证成交。

骨架：**定方向 → 找主要矛盾 → 给动作（量+价+分批）→ 写改判 → 收口**。

#### 硬规则

- 禁词：注意风险、保持谨慎、密切关注、综合来看、整体合理、酌情处理、有望、可能上涨、保证、必涨、胜率。
- 每句带数字；没有的数写「缺失」并说明缺哪个字段。
- 不给目标价，不预测点位，不写「概率很大」这类无样本量判断。
- 给动作时同时给失效条件。
- 心态话只写可诊断的：「这次是信号变了还是情绪变了」——只有信号变了才写动作。

实现：`rsBriefSections()`、`rsRenderBrief()`、`webgen._brief()`、`skills/portfolio-brief/SKILL.md`。

### 4.3 持仓明细表

| 列 | 显示 | 怎么算 | 缺数据 |
|---|---|---|---|
| 名称 / 代码 | 沪深300ETF（510300） | 直接取 | 名称缺只显示代码 |
| 板块 | 主要投向 | 指数行业权重最大项 | 「行业未覆盖（数据日 X）」 |
| 仓位（现→目标） | 20.3% → 8.9% | 现：市值÷总资产；目标：目标仓位表 | 「目标缺失」 |
| 数量（现→建议） | 30,000 → 21,900 | 向下取整（总资产×目标仓位%÷挂单价÷100）×100 | 只显示当前 |
| 本次操作 | −8,100 | 建议数量 − 现在数量 | 「—」 |
| 挂单价 | 4.051 | 买：现价×1.0001；卖：现价×0.9999 | 「不挂单」+原因 |
| 费用 | ¥4.1 | max(5, 成交额×0.5bp) + 成交额×1bp | 「—」 |
| 成本 → 现价 | 4.120 → 4.052 | 直接取 | 「—」 |
| 盈亏 | −1.7% / −¥2,040 | （现价−成本）÷成本；金额=差价×份额 | 「—」 |
| 5/20 日上涨占比 | 46% / 43% | 历史相似条件统计 | 样本<30 整列隐藏 |
| 全市场位置 | 弱于基准 0.8pct | 近 5 日涨幅 − 大盘 5 日涨幅 | 「—」 |
| 国家队 | 沪深300 减持 0.3% | 该宽基近 25 天份额变化 | 「未纳入」 |
| 动作 | 减仓 −11.4pct | 目标仓位表 | 「—」 |

约定：

- 排序：按本次操作金额降序，不动的靠后。
- 格式：份额千分位；价格三位小数；费用到分。
- 动作必须等于订单方向；不一致整行标橙并写「以订单为准」。
- 每行 `title` 带规则编号，便于回查。

下单信息六条边界：

| 情况 | 处理 |
|---|---|
| 目标仓位缺失 | 数量、价格全「—」，备注「目标缺失」 |
| 价格缺失 | 同上，备注「价格缺失」 |
| 不足 100 份 | 视为不动，备注「不足一手」 |
| 买入现金不足 | 按可用现金下调手数，备注「受现金限制」 |
| 当日成交额 < 1000 万 | 不挂单，备注「流动性不足」 |
| 停牌 / 涨跌停封死 | 不挂单，备注原因 |

## 5. 第二部分 持仓分析

读法：三层递进，每层开头一句话结论，然后给证据，最后一行写「这一层约束了下面什么」。

```
1. 市场环境  → 得出：总仓位上限、能不能进攻
2. 组合情况  → 得出：方向对不对、额度怎么分、哪块要收
3. 个股分析  → 得出：这一只怎么下手（量、价、止损）
```

### 5.1 市场环境

五个小块：大盘位置、热度与情绪、资金动向、隔夜与消息、国家队；末尾附位置与赔率。

#### 5.1.1 大盘位置

必须逐项显示，不许只给一句状态：

| 项 | 显示 | 判据 |
|---|---|---|
| 指数点位 | 基准收盘 | 直接取 |
| 均线排列 | 5/10/20/120 日线的顺序与方向 | 5、10 在 20、30 之上且右上倾斜 = 多头；反之空头；三线间距 <1.5% 记「缠绕，等变盘」 |
| 五均线开关 | 收盘是否站回 5 日线，连续几天 | 站回且连续 3 日 = 短线转多；只站 1 天不算 |
| 量能 | 今日成交额、近 5 日 vs 前 5 日 | 缩量 / 平量 / 放量（±10% 为平） |
| 缺口 | 近 20 日未回补的跳空位置 | 上方缺口未补 = 多头没信心；缺口回补才有像样行情 |
| 空间 | 距前高、距前低、上下空间比 | 赔率 = 向上空间 ÷ 向下空间，只描述位置 |
| 波动 | 20 日 vs 60 日实现波动 | 抬升 → 总上限再降 10 个百分点 |

判据表（只走这一条）：

| 收盘 vs 60 日线 | 5 日线 vs 20 日线 | 状态 | 总上限 |
|---|---|---|---|
| 上方 | 上方 | 上行趋势 | 85% |
| 下方 | 下方 | 下行趋势 | 35% |
| 其余 | — | 震荡区间 | 65% |
| 20 日波动 > 60 日波动×1.25 | — | 追加「波动抬升」 | 再降 10 |

一句话结论示例：「空头排列 + 缩量 + 距前低 0.8%，没放量急杀，是阴跌不是恐慌」。

→ 约束下一层：这个上限决定组合总仓位，个股再强也不能突破。

#### 5.1.2 均线各自管什么（写进页面，减少误读）

| 均线 | 作用 | 用法 |
|---|---|---|
| 5 日线 | 短线多空分界 | 上方短线持有；跌破短线走弱 |
| 10 日线 | 短期趋势线 + 交易仓成本线 | 上方趋势完好；连续 2 日跌破 → 交易仓出局 |
| 20 日线 | 中期生命线 | 跌破且 2 日不收回 → 减半 |
| 30 日线 | 中期牛熊线 | 跌破且 2 日不收回 → 清差额 |
| 60 日线 | 长期趋势线 | 上方回调是正常调整；跌破趋势可能逆转 |
| 120 日线 | 多空转折点 | 站上才算主力进场；站不上，多头结论降一档 |
| 20 月线 | 牛熊分界线 | 站上可重仓；之下一切上涨视为反弹 |

#### 5.1.3 市场热度与情绪

| 项 | 显示 | 判读 |
|---|---|---|
| 涨跌家数 | 涨/跌/平，上涨占比 | >55% 赚钱面广，<45% 偏窄 |
| 涨停 / 跌停 / 连板高度 | 家数与最高连板 | 跌停家数上升 = 情绪恶化 |
| 成交额与环比 | 金额与百分比 | 环比 −5% 以下记「缩量」 |
| 恐慌形态 | 是否放量急杀 | 只有放量急杀才算恐慌；缩量阴跌不算 |
| 连续普涨/普跌 | 连续几日 | 连续 2 日普涨 → 次日易分歧，不追；连续 3 日普跌 → 情绪悲观，只做试错仓 |
| 地天板 / 天地板 | 有无及次数 | 情绪极端摇摆的标尺 |
| 情绪温度 | 0–100 + 四项分项 | 情绪 40% + 涨跌家数 35% + 成交额 15% + 趋势 10% |

#### 5.1.4 资金动向

| 项 | 显示 | 说明 |
|---|---|---|
| 两市主力资金 | 净流入 / 净流出金额 | 日频 |
| 两融 | 融资余额、融资净买入 | 日频 |
| 北向 | 不显示，只写一句说明 | 2024-08 起不再盘中披露净流入；不要留空让人以为漏了 |
| 板块成交占比 | 各行业占全市场成交额 | >15% 记「过热」 |

#### 5.1.5 隔夜与消息

- 隔夜：美股三大指数、A50 期指、原油黄金铜。只算开盘扰动，不改自身周期。
- 消息：政策 / 快讯，给情感分（−1~+1）与重要性（1–10），只列前 3。
- 宏观事件窗口：议息、CPI、重要会议前 48 小时标「静默期，仓位不增不减」。

#### 5.1.6 国家队

六类宽基最新份额、较上次增减、近四周方向。近四周按日期回溯 25 天，不按条数取（日频取 4 条只有 4 天）。
只当背景：影响总上限 ±5 个百分点以内，不破上下限；单期变化 >15% 标「仅展示，不作判断」。

#### 5.1.7 位置与赔率

近 120 日最高最低、距高点、距低点、向上空间、向下空间、赔率。
必须加一句解释：赔率是位置描述，不代表发生可能；贴近前低时赔率会显著放大。

→ 约束下一层：赔率低 + 距离前低近 → 组合层只做减仓与结构切换，不新增方向。

实现：`signals/market_regime.py`（状态、上限、均线、位置）、`rsRenderMarket()`、`nationalTeamTable()`、`marketOutlook()`。

### 5.2 组合情况

四块：板块评分与评级、覆盖度、集中度、与市场一致性；末尾纪律闸门。

#### 5.2.1 板块评分（四维，0–100）

板块强度 = 技术 40% + 资金 25% + 政策 20% + 情绪 15%。

| 维度 | 取什么 | 缺失 |
|---|---|---|
| 技术 40% | 该行业代表 ETF 的周线 MACD 方向、5/10/20/30 周排列、是否站上 20 周线 | 权重按已有项折算 |
| 资金 25% | 板块成交占比变化（近 5 日 vs 前 5 日）+ 主力净流入天数 | 同上 |
| 政策 20% | 政策热度表里该主题的热度与变化 | 无对应主题记缺失 |
| 情绪 15% | 当日涨跌幅 + 涨跌家数占比 | 同上 |

缺项不直接不算，按比例分给已有项（例缺政策面：技术 40→50、资金 25→31、情绪 15→19），标题旁标「缺 1 项」。

评级与单板块上限（与个股同一套分档，便于比较）：

| 分 | 评级 | 单板块上限 | 处理 |
|---|---|---|---|
| ≥85 | S | 25% | 核心，回踩加 |
| 75–84 | A | 20% | 持有 |
| 60–74 | B | 10% | 中等，等升级 |
| 50–59 | C | 5% | 观察，不加 |
| <50 | D | 0% | 只保留观察，不加 |

#### 5.2.2 覆盖度（组合跟不跟得上）

| 判断 | 做法 |
|---|---|
| 主线是谁 | `rotation.leaders` + 政策热度前 2，取前三个方向 |
| 覆盖了没有 | 组合行业暴露 vs 主线 → 覆盖 / 低配（<5%）/ 未覆盖 |
| 主线过热没有 | 板块成交占比 >15% → 过热，即便覆盖也不加 |
| 企稳没有 | 板块指数是否收盘站回 5 日线；站不上只是反弹 |
| 有没有反包证据 | 是否「扛过分歧后再次反包」；没有证据写「未确认」 |
| 没跌够的 | 与同期跌幅最小者比较；没跌够的方向往往补跌，不追 |

输出三句：「覆盖了 X（占比 a%）；缺 Y（0%），受额度限制只观察；Z 已过热，不加」。

轮动信号（判断「要不要换方向」）：

| 信号 | 含义 | 动作 |
|---|---|---|
| 领涨板块滞涨 + 低位板块放量 | 轮动将至 | 减高位、配低位（受额度约束） |
| 领涨板块成交占比 >15% | 情绪过热 | 不加，考虑减 |
| 低位板块持续缩量 | 轮动条件不具备 | 不切换 |
| 高位板块龙头破位 | 主线可能切换 | 减高位 |

#### 5.2.3 集中度

| 指标 | 公式 | 提示线 |
|---|---|---|
| 最大板块 | max(暴露) | ≥25% 超配，≤5% 低配 |
| 前三大合计 | top3 之和 | >60% 记集中 |
| 持有只数 / 有效只数 | 只数 / 1÷HHI | — |
| 现金比例 | 现金 ÷ 总资产 | 下限 5% |
| 同主题合并 | 半导体+科创+存储合并算 | 合计 ≤35% |

#### 5.2.4 与市场是否一致 ⓘ

三条判断，逐条给结论，标题右侧 ⓘ 展开计算思路：

1. 最大暴露板块是否属于当前主线（跳过「未覆盖」「其他」）。
2. 超配（≥25%）与低配（≤5%）清单。
3. 走弱（评级 C/D）但仍有暴露（≥10%）的清单 → 逐条给收紧方向。

ⓘ 交互：标题右侧圆形图标，可键盘聚焦，`aria-label` 写「查看计算思路」；点击在区块内展开浅底说明，再点收起；不跳页、不弹层、不遮挡表格；移动端同样可用。
ⓘ 内容：输入字段、阈值、缺项处理、以及「这条判断怎么约束下一层」。

→ 约束下一层：走弱板块对应的个股不得加仓；未覆盖的主线只能通过候选观察，不直接买。

| 闸门 | 规则 | 页面表现 |
|---|---|---|
| 单板块止损 | 板块层面亏 −5% | 无条件减该板块全部差额 |

#### 5.3.1 进场检查（选股三步）

| 步骤 | 要看到什么 | 页面显示 |
|---|---|---|
| 第 0 步 环境 | 大盘没企稳时，个股再好也只做试错仓 | 引用 5.1 的总上限，不重复判断 |
| 第 1 步 底部震荡 | 长下影或止跌 K 线，两根 K 线确认不创新低；震荡 1–3 个月 | 「震荡第 N 周」；只写「不跌了」，不写「要启动了」 |
| 第 2 步 放量突破 | ① 5/10 日线在 20/30 日线上方且向上 ② 突破当天实体阳线、无长上影 ③ 股价在 120 日线上方 | 逐条 ✓/✗，缺一条写「突破不成立」 |
| 第 3 步 回踩确认 | 不破关键位 + 明显缩量 + 慢跌快涨 + 有承接 | 「回踩确认 / 未确认」；假突破：放量下跌且跌破重要均线 |

三条最容易搞混：

- 突破当天不是买点，只标「关注」；回踩才是确认。
- 量能口径：突破放量、回踩缩量。放量回踩 = 有人在跑。
- 120 日线是多空转折点，站不上时所有多头结论降一档。

#### 5.3.2 双评分卡

底部评分（100）：

| 信号组 | 权重 | 计分 |
|---|---|---|
| 估值压缩 | 10 | PE 分位 <10% 得 10；10–15% 得 6；15–20% 得 3 |
| 月线底背离 | 25 | 双重 25 / 单一 15 / 未确认 8 / 无 0 |
| 月线倍量站上 20 月线 | 20 | 放量站上 20 / 缩量站上 10 / 未站上 0 |
| 周线多头排列 | 15 | 多头 15 / 金叉 10 / 粘合 5 / 空头 0 |
| 领先股出现 | 15 | 该行业 ≥2 只龙头创半年新高 15 / 1 只 8 / 无 0 |
| 宏观景气 | 10 | 核心指标连续 2 月转好 10 / 转好 5 / 恶化 0 |
| 资金流向 | 5 | 连续 3 周净流入 5 / 1–2 周 3 / 净流出 0 |

顶部风险评分（100）：

| 信号组 | 权重 | 计分 |
|---|---|---|
| 估值极端 | 15 | PE 分位 >90% 得 15；85–90% 得 12；80–85% 得 8 |
| 月线顶背离 | 30 | 价格新高 + 红柱萎缩 30 / 背离未确认 15 |
| 跌破 10 月线 | 20 | 视为大波段结束 |
| 周线死叉 | 15 | 死叉 + 破 30 周线 15 / 仅死叉 10 |

| 龙头破位 | 10 | 最强个股月跌 >20% 得 10；>10% 得 5 |

两张一起看：底部高 + 顶部低 = 可加；底部低 + 顶部高 = 减；两张中性 = 持。
未接入的项（估值、领先股、景气）标「未接入，按已有项折算」，不假装有分。

| 底部分 | 评级 | 单只上限 | 处理 |
|---|---|---|---|
| ≥85 | S | 25% | 核心，回踩加 |
| 75–84 | A | 20% | 持有 |
| 60–74 | B | 10% | 中等，等升级 |
| 50–59 | C | 5% | 观察，不加 |
| <50 | D | 0% | 只保留 ≤3% 观察仓，反弹减；不清零是因为跳空多，一次清仓常卖在最低 |

顶部风险 ≥60：上限在原基础上打七折，并标「顶部风险」。

#### 5.3.4 多空分界（按品种类型）

| 品种 | 分界指标 | 多头确认 | 空头确认 |
|---|---|---|---|
| 进攻型（科技/算力/半导体） | 20 日线 | 站稳 20 日线 + 量 >5 日均量 1.2 倍 | 跌破 20 日线 + 缩量 |
| 防御型（红利/公用/绿电） | 30 日线 | 站稳 30 日线 | 跌破 30 日线 |
| 周期型（资源/有色/黄金） | MACD 零轴 + 60 日线 | 零轴上方 + 站上 60 日线 | 零轴下方 + 跌破 60 日线 |

多空区域：站上 20 日线且 20 日线向上 = 多头区域；跌破且向下 = 空头区域；20 日线走平 + 反复穿越 = 转换，轻仓观望。
日线信号服从周线方向：周线向上，日线回踩是买点；周线向下，日线反弹是卖点。

#### 5.3.5 结构图（缠论，明确边界）

分型 → 笔 → 中枢 → 背驰 → 买卖点。

| 步骤 | 规则 |
|---|---|
| 分型 | 左右各 2 根的顶/底 |
| 笔 | 顶底交替、间隔 ≥4 根、幅度 ≥1.5% |
| 中枢 | 最近三段笔的重叠区间：上沿 = min(各段高)，下沿 = max(各段低)，上沿>下沿才有效 |
| 底背驰 | 价格创新低而 MACD DIF 抬高 |
| 买卖点 | 只标「底背驰（一类买点候选）」「回踩中枢上沿不破（三类买点）」「跌破中枢下沿（卖点）」 |

不做线段、不做多级别递归，图注写「简化实现」。不许出现「第 18 根买点」这类固定位置标注。

#### 5.3.6 概率

用「20 日涨幅 + 20 日波动」找历史上最相似的样本，按距离加权统计未来 5/20/60 日上涨占比，同时给样本数、样本区间、中位涨幅。
样本 <30 显示「样本不足」；概率不改评级、不改动作。

#### 5.3.7 执行位（把纪律写进价格）

先分仓位用途，再谈止损——两套口径不能混用：

| 仓位类型 | 适用 | 止损 |
|---|---|---|
| 交易仓 | 试错/波段，单票 ≤10%，评级 C/B | 收盘连续 2 日跌破 10 日线 → 出局 |
| 核心仓 | 评级 A/S，目标仓位 ≥10% | 破 20 日线 2 日减半；破 30 日线 2 日清差额；破 60 日线立即 |

其余（两类共用）：

| 项 | 规则 |
|---|---|
| 买点一 | 缩量回踩 5 日线或震荡区上沿不破 |
| 买点二 | 沉淀区再次突破新高；跌破 5 日线即出 |
| 加仓确认 | 站上 10 日线 / MACD 金叉 / 主力连续 2 日净流入，至少两条 |
| 兑现 | +25% 减 1/4；+40% 再减 1/4；+50% 清 |
| 短线（小仓） | 3 日 10%+ 先保护利润；30 分钟放量滞涨或次日冲高无力先出 |

#### 5.3.8 改判

每只必须写两条，带阈值：一条「转好怎么办」，一条「恶化怎么办」。
示例：「站上 20 日线且周线转多 → 目标回到 8.9%；收盘连续两日破 30 日线 → 卖出全部剩余差额」。

实现：`legScore()`、`rsRenderDetail()`、`rsChanOf()`、`rsDrawChart()`、`rsForecast()`。

## 6. 第三部分 市场洞察及方向

定位：给位置、给冷热、给三种走法，不给「明天涨跌」。

### 6.1 今日定性（时段感知）

时段：盘前 05:00–09:25 / 盘中 09:30–11:30、13:00–15:00 / 午盘 11:30–13:00 / 盘后 / 周末 / 假日。
时段只决定看什么：盘前看隔夜与开盘预判，盘中看量能承接，盘后看次日与结构确认。

打分：大盘状态 ±2、5 日线与 20 日线关系 ±1、上涨家数占比 ±1、情绪分 ±1；|合计| ≥2 才给偏多/偏空，否则震荡。
下面必须列三条依据，覆盖不同维度（位置、量能、情绪），不许三条都讲均线。

### 6.2 情绪与主线

- 涨停/跌停/连板、成交额与环比、恐慌形态、连续普跌天数（与 5.1.3 同一份数据，不另算）。
- 主线：写名字 + 三条判据（分歧节点、首次分歧是否已过、次日是否不破 5 日线），三条齐了才写「反包确认」。
- 落后方向：注明「没跌够的不追反弹」。
- 先跌先稳：列先跌板块与是否先企稳。

### 6.3 情景与触发

三行表：情景 / 触发 / 当前距离 / 动作。

| 情景 | 触发 | 动作 |
|---|---|---|
| 偏弱延续 | 收盘跌破近 120 日最低 | 按差额分批减，不抄底 |
| 震荡修复 | 在前低与 20 日线之间 | 只调结构，不加总仓 |
| 转强确认 | 站上 20 日线且 5 日线上穿 20 日线 | 差额可执行 |

触发值必须是真实价位，不许写「20 日线 ×0.96」；每行写「当前距离」：还差几个百分点。

### 6.4 新方向候选

筛选：观察池 → 去掉已持有 → 板块评级 B 及以上 → 近 5 日不弱于大盘 → 同类只留一只 → 看剩余额度。
额度闸门：剩余额度 <3 个百分点或目标仓位表缺失 → 一律「观察」并说明原因。
不内置固定名单；没额度不写「可分批」；不含不碰名单里的方向。

## 7. 一致性与关联度

### 7.1 决策唯一入口

唯一出口是目标仓位表。差额 = 目标 − 现在；动作由差额与确认条件派生；订单由动作派生。
页面上任何动作（表格、个股卡、点评、洞察）都必须与它一致；不一致以它为准，并把不一致标出来。

### 7.2 规则卡的位置

规则卡只做两件事：

1. 数据闸门：数据不足就放弃，不给动作。
2. 最早减仓时点：跌破关键位后允许提前减，但不改变目标仓位的大小。

规则卡不覆盖目标仓位。这样「上下两套结论」从源头消失：规则决定「什么时候可以动」，目标仓位决定「动到多少」。

### 7.3 组合覆盖

组合层输出三件事供下层引用：主线覆盖情况、板块评级与单板块上限、超配与走弱清单。
个股加仓需同时满足：板块评级 ≥B、未超单板块上限、个股确认条件 ≥2 条。缺一条就不加，并在卡片写明缺哪条。

### 7.4 执行后估算

执行后仓位、现金、费用只能由订单派生（同一函数、同一份数量），不做第二遍估算。

### 7.5 分析层的位置

- 个股卡片的一句话结论 = 表格里的动作。
- 点评每句 = 某一层结论的摘要。
- 洞察定性 = 与 5.1 同一份数据算出的同一个值。

|---|---|---|

| 演示 | 离线快照 | 顶部横幅，不得当真实数据 |

### 8.4 目标仓位

```
单只基础 = 单只上限 × 趋势系数（周线多头 1.0 / 金叉 0.9 / 粘合 0.7 / 空头 0.35）
目标仓位 = min(单只上限, 单板块上限, 总上限 × 单只基础 ÷ Σ单只基础)
目标合计 < 总上限时，差额留现金；不为用满额度倒推动作
```

### 8.5 差额与动作

```
差额 = 目标仓位 − 现在仓位
|差额| < 3 个百分点           → 持有
差额 > 3 且 周线向下          → 等待（写明等什么）
差额 > 3 且 加仓确认不足 2 条  → 等待确认
差额 > 3 且 确认 ≥ 2 条       → 加仓
差额 < −3 且 周线空头或日线弱  → 减仓，50/30/20 分批
差额 < −3 其余               → 先减一半差额
```

### 8.6 下单数量、挂单价、费用

```
挂单价  = 买：现价 × 1.0001；卖：现价 × 0.9999
建议数量 = 向下取整（总资产 × 目标仓位% ÷ 挂单价 ÷ 100）× 100
本次操作 = 建议数量 − 现在数量
首批     = 减仓时 min(|本次操作|, max(5% 总资产折份, |本次操作|/3))
费用    = max(5 元, 成交额 × 0.5bp) + 成交额 × 1bp    （ETF 免印花税）
```

`orderTicket` 参考实现：

```javascript
function orderTicket(r, targetW, total){
  if(targetW==null || r.last==null) return {note:'目标或价格缺失'};
  var side = targetW > r.weight ? 'buy' : 'sell';
  var limit = r.last * (side==='buy' ? 1.0001 : 0.9999);
  var shares = Math.floor(total*targetW/100/limit/100)*100;   // 100 份一手，向下取整
  var delta = shares - r.shares;
  if(Math.abs(delta) < 100) return {delta:0, note:'不足一手'};
  var amt = Math.abs(delta*limit);
  var fee = Math.max(5, amt*0.00005) + amt*0.0001;
  return {shares:shares, delta:delta, limit:limit, fee:fee, side:side};
}
```

## 13. 边界

- 缠论为分型→笔→中枢的简化实现，不含线段与多级别递归，图注必须写明。
- 概率是历史相似条件的统计，不是预测；样本少不显示，不参与决策。
- 行业权重来自公开披露，拿不到就写「未覆盖」，不猜。
- 挂单价是限价保护，不保证成交；所有数字都是执行参考，不是承诺。
- 沉关河、拐点等方法的阈值是他们的经验值，用作规则来源，不当作已验证收益；回测结论必须带「历史不代表未来」。
- 持仓只在本机解密，任何情况下不写入仓库。
