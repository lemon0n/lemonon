# 02 市场判断与决策规则

> 素材：沉关河（稳哥）2026-07-05 ~ 2026-11-19 共 46 篇。均为逐字摘引，篇号对应原文合集编号，引用不超过 40 字。

## 1. 大盘判断框架

他判断指数位置与方向，用的是「均线状态 + 量能 + 缺口/黄金分割 + 情绪 + 空间比」的组合，而不是单一指标。

- **五均线是短线多空开关**：#20（10-19）"接下来指数收盘站回五均线，那么短期回暖的确认信号就出现"；#22（10-20）"回到五均线上…短线多头力量已经强于空头了"。
- **均线缠绕 = 变盘/震荡整理**：#31（11-01）"5.10.20均线凝成一股绳"；#40（11-10）"5均线开始上穿10均线…均线开始走向了企稳缠绕的状态"；#38（11-09）给出两条特征：波动空间收窄 + 均线聚集。
- **缺口与黄金分割给具体位置**：#19（10-16）"这种大跌后的跳空缺口，历史上80%都是3-5天以内就回补的"；#12（09-28）创业板"2683.90-2700.28这一带"；#24（10-22）"0.382到了"。
- **量能权重最高**：#25（10-25）"最重要的是成交量；有量自然会有机会"；#33（11-02）"形态、k线、均线，主力可以画图，但是唯独成交量没法作假"；#17（10-13）引用"地量见地价"，当日"全天预估不到1.5万亿"。
- **日内时点**：#25"9.30-10.30这一个小时，是全天盘口最重要的时候"。
- **空间比**：#42（11-17）"上下空间比在1比4的样子…向下还有20%，向上有80%的空间"。
- **区间中枢**：#18（10-14）"价格中枢在3400附近，最近从4300直接杀到今天2866"。
- **背离与K线形态**：#19"90分钟级别的上证指数,macd出现了底背离"；#27（10-27）"180分钟级别，都出现了底背离信号"；#33"放量红色十字星"。

## 2. 周期与节奏观

- **固定链条**：c 浪下杀 → c 杀结束（放量急杀）→ 缩量震荡整理、均线缠绕 → 翻转。#31："放量急杀后,c杀走完,随后迎来了震荡整理,均线缠绕的形态"。
- **反转需要时间**：#45（11-18）"历史上的反转没有哪个是一天就直接一根阳线拉回来的，都是逐渐2-3个月走出来的"；#34（11-04）"创业板指数下跌2000点,基本腰斩了"。
- **底部是区间不是点**：#31"底部从来不是一个点，而是一段磨人的区间"；#45"阶段底部附近，筹码比现金更值钱"。
- **底部特征清单**：白马股轮流大跌（#7，09-21："业绩优良且市值千亿…这是市场即将出现阶段性底部的信号"）；利好当天板块集体跌停（#13，09-30 地产）；指数"每天没有低于3个点的波动"（#30，10-30，类比22年4月底）。
- **必须区分市况**：#13"多头行情里,出利空常常低开高走…空头行情…资金都会理解成利好落地 = 兑现跑路"。
- 他给波段设了固定验收期：#45"早在10.25日，稳哥跟大家来了一个三月之约"。

## 3. 资金与主力视角

- **先问谁在买卖**：#23（10-21）"今天早盘已经创出最近成交量新高,整整216亿的成交额…当下谁在买,谁在卖呢?" 结论是"让市场散户主动放弃手里的廉价筹码"。
- **主力借消息洗盘**：#23 端侧、医药、电池"闪崩"同一手法；#46（11-19）"当下市场，稳哥是觉得没有正常人了，全是量化在搞"，"每天固定一点砸盘"。
- **大资金流入当证据**：#19"沪深300etf,一天干了过去一个月的成交量总和"，单日"流入近200亿"；#34"一天买了1000亿"。
- **权重先行**：#14（10-08）"宁德是先于创业板下杀的,破新低后向下杀了17%"，其企稳"对指数也有一个正向积极作用"。
- **龙头/业绩分层**：#36（11-05）"市场正在从情绪炒作转向逻辑炒作"，正宗龙头才受关注；#33"权重搭台,题材唱戏"。

## 4. 板块与主线选择

- **主线定义**：#40（11-10）"主线从来不是猜出来的，是扛过分歧后确认出来的。它是市场的合力"。判据是"扛过分歧后出现再次反包"（当日机器人）。
- **主线在横盘期决胜**：#38（11-09）"反弹主线往往都是这个阶段决胜出来的"，要找"板块反弹的持续者"。
- **先跌先稳**：#20（10-19）"先于市场下跌的通常先于市场企稳"（#17 同）——由板块见顶日早于指数见顶日推导（#32：电池5.14见顶、创业板6.23见顶）。
- **筛选三问**：#45"业绩是否有支撑…个股是否处在低位状态…最近半个月成交量是否放大了"。
- **常驻方向**：固态电池、端侧AI芯片、算力、光模块/CPO、机器人、创新药、金融、商业航天。#19 给电池排产业链顺序："2030年要量产，最先是设备，然后材料段，最后产品端"。

## 5. 情绪面判读

- **情绪先于大盘**（反复出现的核心断言）：#14"情绪先于大盘"；#3（09-15）"情绪先于大盘,这句话至少值5、6、7、8个涨停板"。
- **恐慌的物理形态**：#10（09-23）"恐慌必须是放量急速下杀的,而今天极度缩量"。
- **连板高标跌停打开 = 回暖**：#3"三个龙头都打开跌停,且出现有承接的信号"。
- **连续普跌 2-3 天 = 试错点**：#4（09-16）"每次普跌两三天或者出现恐慌节点,我们去试错"。
- **地天/天地板作情绪标尺**：#46"周二地天；周三天地；今天地天"，"股价每天波动在20多cm"，"从周一拿着不动…只变动3%"。
- **看空人数反向**：#44（11-18）"31%的人认为会继续上涨，69%的人认为会下跌"，且那张图是"创业板指数的倒转k线"；#28（10-28）投票"55开"被判失真，"看空下杀的比例大概率会到70%"。
- **PTSD**：#46"把市场都搞出ptsd"，"看见市场上涨觉得不正常"。
- **拐点不可测、位置可判**：#15（10-08 晚）引霍华德·马克斯"极端悲观时,负面信息被过度定价,利好被视而不见"。

## 6. 决策规则清单

1. 指数收盘站回五均线 → 短线回暖确认、可加仓做 T（#20，10-19）。
2. 个股/板块缩量回踩五均线 → 波段关注点（#37，11-06："标准的缩量回踩五均线"）。
3. 长期下跌后缩量跌不动 + 放量三连涨站回五均线 → 阶段性底部信号（#6，09-21："由空头转变为多头的信号"）。
4. 连续两天普涨 → 次日易分歧，不追（#6："短线连续两天普涨,次日容易分歧回调"）。
5. 连续两三天普跌/出现恐慌 → 短线试错（#4）。
6. 30分钟K放量滞涨 → 短线阶段顶，先兑现（#6）。
7. 尾盘无量拉升 + 金融偷袭 → 短线先防守（#7，09-21 晚："无量拉升说明多头资金并没有过多流入"）。
8. 板块遇王炸利好当天却跌停 → 情绪过度悲观，接近反转（#13）。
9. 下跌日放量（非缩量）→ 资金回流，波段机会酝酿（#14："今早是放量2000亿"）。
10. 金融权重放量单边涨 → 题材大机会随后（#33："如果金融这边接下来还能继续放量"）。
11. 5均线上穿20均线 → 市场扭转信号（#38）。
12. 指数到 2683.90-2700.28 → 左侧"主动买套"（#12）。
13. 上方缺口未回补 → 多头没信心、行情焦灼；回补后才"一大波"（#19）。
14. 外围暴跌 → 只影响开盘，是踏空者补票机会（#37，11-06："外围恐慌消息,只会影响开局"）。
15. 反弹属下跌中继 → 控仓、快进快出（#17："这一波反弹同样属于下跌中继的短线反弹"）。

## 7. 宏观/政策/外围变量的作用

- **政策底先于市场底**：#32（11-02）"第一个ZC底出现…技术上还会再回踩一次,出现一个技术上的市场底"。
- **制度与利率**：#33"长期性制度…以后只要下跌，就可以常态化拿出来使用"，利率再降降低融资成本。
- **会议即催化**：#31"上一次开完会,市场就开始干活了"；11月为"业绩真空期"，题材催化更多。
- **外围被降级**：#4 面对美联储议息"好好睡觉,这事没那么重要"，理由是"a股市场有自己的一个运行周期"；#37 美股科技暴跌、费城半导体"跌了10多cm"，仍只算开盘扰动。

## 8. 矛盾与摇摆（并列不调和）

- **10-08 vs 10-30**：10-08"波段机会正在酝酿"并宣布"从今天开始,这一条作废!"（不再劝减科技仓）；10-30 自认"之前短线搏击反弹算是失败了,这个得承认"。
- **11-02/11-04 vs 11-18**：11-02"市场反转可能要来了"、11-04"从周期来看这里就是反转的信号"；11-18 改口"我从来没说市场一定会反弹或者反转"。
- **11-09 vs 11-17/11-19**：11-09 定义为"正式进入横盘整理阶段"（弱化反转）；11-17 用"1比4…向上有80%的空间"重新给出强多头赔率；11-19 用"4380到今天2300，跌了一半了"以周期兜底。
- **情绪读数摆动**：10-08 午间"高位的恐慌情绪正在退却"；10-08 晚间又称"市场正处在极度悲观状态"；10-21 说"当下情绪很明显有点过头了"。
- **量能口径不一致**：10-25 写"看量能能否持续维持在1.8亿以上"（原文如此，与前后文万亿级成交口径不符），10-13 用"不到1.5万亿"——同一指标两套量级表述。
